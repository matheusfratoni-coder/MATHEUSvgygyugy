📌 Contexto Geral

  • Dispositivo: Celular antigo com tela trincada.
  • Conexão: Dados móveis limitados e Wi-Fi compartilhado.
  • Moradia: Bairro periférico com infraestrutura de rede instável.

⚠️ Principais Dores

  • Dificuldade para formatar trabalhos no celular.
  • Ansiedade em relação ao desempenho no ENEM.
  • Falta de tempo no laboratório da escola (poucos PCs).
"Enquanto muitos estudam por plataformas completas com simulados no computador, eu preciso economizar a franquia do celular até para baixar um arquivo PDF."

🔍 Mapeamento do Problema


Quem sente o impacto?

Alunos sem recursos, professores limitados nas aulas, famílias sobrecarregadas financeiramente e a comunidade escolar diante de baixos rendimentos institucionais.

Quando o problema surge?

Diariamente nas pesquisas de casa, no envio de tarefas fora da escola e, principalmente, durante a preparação para o ENEM e vestibulares.

🚀 Como Publicar este Site no GitHub Pages

Siga os passos abaixo para gerar um link público gratuito para seu trabalho:

  1. Crie uma conta gratuita em github.com.
  2. Clique no botão "New" para criar um novo repositório.
  3. Dê o nome ao repositório (ex: meu-trabalho-escola) e marque como Public.
  4. Envie este arquivo com o nome exato de index.html.
  5. Vá em Settings > Pages (no menu lateral).
  6. Em Source, selecione a branch main e clique em Save.
  7. Seu link ficará disponível após alguns minutos!
